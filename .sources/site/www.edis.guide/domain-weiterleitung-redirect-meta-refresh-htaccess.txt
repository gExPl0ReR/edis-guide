# Domain weiterleiten: Redirects und .htaccess

5 min

Es gibt verschiedene Wege, um eine Webseiten-Weiterleitung zu konfigurieren.

### [1. Meta refresh](https://www.edis.guide/domain-weiterleitung-redirect-meta-refresh-htaccess#1-meta-refresh)1\. Meta refresh

Erstellen Sie auf Ihrem Webhost eine Datei index.html mit zB: folgendem Inhalt:

HTML

1<html\> 2 <head\> 3 <meta http-equiv\="refresh" content\="5; URL=https://www.weiterleitungsziel.domain"\> 4 <title\>Meine Webseite</title\> 5 </head\> 6 <body\> 7 </body\> 8</html\> 

<html> <head> <meta http-equiv="refresh" content="5; URL=https://www.weiterleitungsziel.domain"> <title>Meine Webseite</title> </head> <body> </body> </html>

### [2. Weiterleitung mittels .htaccess](https://www.edis.guide/domain-weiterleitung-redirect-meta-refresh-htaccess#2-weiterleitung-mittels-htaccess)2\. Weiterleitung mittels .htaccess

Erstellen beziehungsweise bearbeiten Sie die .htaccess-Datei im tatsächlichen Document-Root der betroffenen Website. Sichern Sie vorhandene Regeln und stimmen Sie die gewünschte Weiterleitung mit der Websitebetreuung ab.

(im DocRoot zB: **/www/home/** - oder wenn die Domain in ein Unterverzeichnis zeigt **/www/home/unterverzeichnis/** )

.htaccess

1Redirect 301 / https://www.weiterleitungsziel.domain 

Redirect 301 / https://www.weiterleitungsziel.domain

HTTP 301 kennzeichnet eine dauerhafte Weiterleitung und ist ein Signal für Suchmaschinen, die Zieladresse zu bevorzugen. Eine sofortige Entfernung der alten Adresse aus dem Suchindex ist damit nicht garantiert. Das gezeigte Redirect-Beispiel kann den angehängten Pfad weitergeben; testen Sie daher auch Unterseiten und benötigte Parameter.

Wenn es sich um eine temporäre Weiterleitung handeln soll, verwenden Sie den Code 302. Damit wissen Suchmaschinen Bescheid, dass es sich nur um eine zeitlich begrenzte Weiterleitung handelt.

### [3. Redirect als Service](https://www.edis.guide/domain-weiterleitung-redirect-meta-refresh-htaccess#3-redirect-als-service)3\. Redirect als Service

Ohne eigenen Webhost können Sie einen passenden Weiterleitungsdienst im Kundenbereich unter [https://manage.edis.at](https://manage.edis.at 'https://manage.edis.at') einrichten. Verwenden Sie dafür das aktuell bestätigte DNS-Ziel des Dienstes. Prüfen Sie Hauptdomain, www und HTTPS sowie den Erhalt benötigter Mail-Einträge. Die bisher genannte IP-Adresse ist keine allgemeine Vorgabe für jede Domain und jede Hostingzuordnung.

Je nach Domain-Tarif ist dafür u.U. das Zusatzprodukt ("Aktive Nutzung") nötig.
