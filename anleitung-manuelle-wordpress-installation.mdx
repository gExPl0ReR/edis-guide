Diese Anleitung beschreibt die manuelle Installation von WordPress. Für eine verwaltete Installation mit Sicherungsfunktionen können Sie auch den EDIS-App-Installer verwenden.

## Vorbereitung

Bevor Sie beginnen, benötigen Sie:

- **Webhosting und Domain:** Prüfen Sie, welches Verzeichnis Ihrer Domain zugeordnet ist. Dieses Website-Stammverzeichnis wird auch **Document-Root** genannt.
- **Passende Umgebung:** Prüfen Sie die Anforderungen der gewählten WordPress-Version und die [eingestellte PHP-Version](/php-version-domain-subdomain-bei-edis-einstellen).
- **MySQL-Datenbank:** Erstellen Sie die Datenbank über die Hostingverwaltung und halten Sie Datenbankname, Benutzername, Passwort und Datenbankhost bereit.

<Warning>
  Prüfen Sie eine aktuelle Sicherung und die Zuordnung von Domain, Website-Verzeichnis und Datenbank. Überschreiben Sie keine vorhandene Website ungeprüft.
</Warning>

## Installation in sechs Schritten

<Steps>
  <Step title="WordPress herunterladen">
    Öffnen Sie [de.wordpress.org](https://de.wordpress.org/), klicken Sie auf **Herunterladen** und laden Sie die aktuelle WordPress-Version herunter. Entpacken Sie anschließend die ZIP-Datei.
  </Step>

  <Step title="Dateien hochladen">
    Laden Sie die entpackten WordPress-Dateien in das Hauptverzeichnis Ihrer Website oder in das gewünschte Unterverzeichnis hoch.

    Verwenden Sie eine **verschlüsselte Verbindung**:

    - **FTPS** für einen entsprechend eingerichteten Dateizugang
    - **SFTP**, wenn Ihr Hostingprodukt SSH bietet

    Übernehmen Sie Server, Port und Benutzer aus den bestätigten Einstellungen Ihres Webhosts. Ein FTP-Benutzer ist nicht automatisch ein SSH- oder SFTP-Zugang.
  </Step>

  <Step title="Installationsassistenten aufrufen">
    Öffnen Sie Ihre Website im Browser. Liegen die Dateien in einem Unterverzeichnis, rufen Sie die entsprechende Adresse einschließlich dieses Unterverzeichnisses auf.

    Wählen Sie **Deutsch** und klicken Sie auf **Weiter**. Bestätigen Sie die Übersicht der benötigten Angaben mit **Los geht’s**.
  </Step>

  <Step title="Datenbank verbinden">
    Geben Sie die folgenden Daten ein:

    - Datenbankname
    - Datenbankbenutzer und Passwort
    - Datenbankhost
    - Tabellenpräfix

    Klicken Sie auf **Absenden**. Sobald die Datenbankverbindung erfolgreich hergestellt wurde, wählen Sie **Installation starten**.
  </Step>

  <Step title="Website und Administratorkonto einrichten">
    Tragen Sie den **Titel Ihrer Website**, einen **Benutzernamen**, ein **Passwort** und Ihre **E-Mail-Adresse** ein.

    Mit dem hier festgelegten Benutzernamen und Passwort melden Sie sich später in WordPress an. Klicken Sie auf **WordPress installieren**.
  </Step>

  <Step title="In WordPress anmelden">
    Klicken Sie nach erfolgreicher Installation auf **Anmelden**. Verwenden Sie den gerade angelegten Benutzernamen und das zugehörige Passwort.
  </Step>
</Steps>

## Nach der Installation

Sie können Ihre Website nun gestalten, Erweiterungen hinzufügen und Inhalte veröffentlichen.

Weitere Details finden Sie in der [offiziellen Installationsanleitung von WordPress](https://developer.wordpress.org/advanced-administration/before-install/howto-install/).
