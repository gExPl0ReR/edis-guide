Der App-Installer kann eine bestehende WordPress-Installation übernehmen, damit Sie sie dort verwalten und beispielsweise Updates und Backups durchführen können.

## Vor dem Import

- **PHP-Version vergleichen:** Prüfen Sie, mit welcher PHP-Version die Website bisher läuft und welche Version auf dem Ziel-Webhost eingestellt ist. Die Zielversion muss zu Ihrer Anwendung passen.
- **Verfügbare Versionen prüfen:** Im vHost-Bereich finden Sie die Auswahl unter **Apache → PHP Version**. Verfügbare Versionen und deren Unterstützung hängen vom gebuchten Produkt ab. Die [Anleitung zur PHP-Umstellung](/php-version-domain-subdomain-bei-edis-einstellen) beschreibt den Weg.
- **Quelle und Ziel festlegen:** Klären Sie, welche Installation übernommen werden soll und unter welcher Domain beziehungsweise in welchem Verzeichnis sie am Ziel liegen soll.

<a className="edis-button" href="https://manage.edis.at/vhost/" target="_blank" rel="noopener noreferrer">vHost-Bereich öffnen</a>

## WordPress importieren

<Steps>
  <Step title="WordPress im App-Installer auswählen">
    Öffnen Sie im vHost-Bereich **App-Installer → Expertenmodus**. Wechseln Sie zum Reiter **Anwendungs Browser** und wählen Sie **WordPress**.

    <Accordion id="import-wordpress-auswahl" title="Screenshot: WordPress auswählen">
      ![WordPress im Anwendungsbrowser des App-Installers auswählen](/images/3a59853398c1a0.png)
    </Accordion>
  </Step>

  <Step title="Import-Assistenten starten">
    Klicken Sie rechts neben **Diese Applikation installieren** auf das Menü mit den **drei waagrechten Strichen**. Wählen Sie **Eine bestehende Installation importieren**.

    <Accordion id="import-menue" title="Screenshot: Import-Menü öffnen">
      ![Menü zum Import einer bestehenden WordPress-Installation](/images/134af9212591ac.png)
    </Accordion>
  </Step>

  <Step title="Passende Importart wählen">
    Wählen Sie die Option, die zum Speicherort Ihrer bestehenden Website passt, und klicken Sie auf **Fortsetzen**.

    | Die bestehende Website liegt … | Wählen Sie … |
    | --- | --- |
    | auf einem anderen Webhost oder Server | **Von einem anderen Konto** |
    | bereits in diesem Hosting-Konto, wurde aber manuell installiert | **Von diesem Konto** |

    Mit **Von diesem Konto** nehmen Sie eine vorhandene Installation in die Verwaltung des App-Installers auf.

    <Accordion id="import-konto-auswahl" title="Screenshot: Importart auswählen">
      ![Installation von einem anderen Hosting-Konto importieren](/images/e680fc52f32746.png)
    </Accordion>
  </Step>

  <Step title="Quelle und Ziel angeben">
    **Beim Import von einem anderen Konto:**

    - Geben Sie unter **Quelle** die Adresse Ihrer bisherigen Website und die passenden Zugangsdaten an.
    - Wählen Sie ein vom bisherigen Hosting unterstütztes Transferprotokoll. Verwenden Sie ein verschlüsseltes Verfahren wie **FTP mit TLS/SSL** oder **SFTP**, wenn es für diesen Zugang unterstützt wird.
    - Prüfen Sie den **Quellpfad**: Wenn der verwendete Dateizugang nicht direkt im Website-Verzeichnis des alten Webhosts startet, müssen Sie den passenden Pfad angeben.
    - Wählen Sie unter **Ziel** die gewünschte Domain. Sie können auch die temporäre Domain verwenden. Berücksichtigen Sie ein gegebenenfalls vorgesehenes Unterverzeichnis, beispielsweise `/www/home/webseite1/`.

    **Beim Import aus demselben Konto:** Geben Sie den Speicherort der bereits vorhandenen Installation an.

    <Accordion id="import-quelldaten" title="Screenshot: Quelldaten und Pfad">
      ![Quelldaten, Transferprotokoll und Pfad der bestehenden WordPress-Installation](/images/896d3d3f6484a2.png)
    </Accordion>
  </Step>

  <Step title="Import durchführen">
    Klicken Sie auf **Importieren**. Nach erfolgreichem Import finden Sie die WordPress-Installation unter **Meine Applikationen**.
  </Step>
</Steps>

## Nach dem Import

1. Prüfen Sie, ob sich die importierte Website korrekt aufrufen lässt.
2. Erstellen Sie ein **Backup**.
3. Führen Sie die benötigten Updates durch und prüfen Sie die Website erneut.
4. Erstellen Sie anschließend ein **neues Backup**.

Weitere Hinweise finden Sie beim [Installatron-Support](https://installatron.com/support).

## Besondere Situationen

<a id="nach-einem-manuellen-domainwechsel-prüfen" />

<Accordion id="dozER" title="Die Website-Adresse wurde manuell geändert">
  Eine geänderte Website-Adresse wird nicht automatisch in jeder Verwaltungszuordnung übernommen. Prüfen Sie diese Punkte getrennt:

  - DNS und einen gegebenenfalls vorgeschalteten Proxy
  - TLS am eigentlichen Webserver
  - die vHost-Zuordnung
  - die im App-Installer registrierte Adresse

  Ein Fehler beim HTTPS-Aufbau kann die weitere Prüfung verhindern. Korrigieren Sie die App-Zuordnung erst, wenn die Zieladresse funktioniert. Testen Sie danach die Anwendung und ein neues Backup. Entfernen Sie die Testdomain erst, wenn diese Schritte erfolgreich sind.

  Ein einzelner Origin-Zertifikatsfehler belegt keine allgemeine Unverträglichkeit mit einem Proxyanbieter. Private Schlüssel gehören ausschließlich in den vorgesehenen sicheren Einrichtungsweg.
</Accordion>

<a id="manuelle-installation-vor-löschen-oder-neuaufsetzen-prüfen" />

<Accordion id="0TqNO" title="Eine vorhandene Installation fehlt unter „Meine Applikationen“">
  Auch ohne Eintrag im App-Installer können Dateien und Datenbanktabellen der Website weiterhin vorhanden sein. Prüfen Sie zuerst, ob sich die Installation über **Von diesem Konto** übernehmen lässt. Eine fehlende Zuordnung bedeutet nicht, dass die Installation entfernt wurde.

  Soll die Website tatsächlich ersetzt werden, ordnen Sie vorher **Domain, Document-Root, Konfigurationsdatei, Datenbank und Tabellenpräfix** eindeutig zu. Sichern Sie die benötigten Inhalte und legen Sie fest, was gelöscht werden soll.

  <Warning>
    Löschen Sie keine ganze Datenbank, wenn andere Anwendungen darin Tabellen verwenden.
  </Warning>

  Eine hohe Dateizahl allein erklärt noch keinen Fehler in der Medienverwaltung.
</Accordion>
