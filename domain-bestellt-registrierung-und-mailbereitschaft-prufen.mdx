Eine Bestellung ist der erste Schritt. Prüfen Sie anschließend Registrierung, Hostingzuordnung und die gewünschten Dienste.

<Note>
**Bereits ein Webhosting vorhanden?** Prüfen Sie vor einer zusätzlichen Bestellung, ob Sie einen bestehenden Webhost verwenden können. Wählen Sie bei der Domainbestellung diesen bestehenden Host, wenn die entsprechende Zuordnung angeboten wird. Kontrollieren Sie die Hostingkennung und die verfügbaren Domainplätze. Fehlt der gewünschte Host in der Auswahl, lassen Sie die Zuordnung vom Support prüfen, statt vorsorglich ein zweites Hosting zu bestellen. Die Auswahl allein bestätigt noch keine fertige DNS-, Website- oder Mailkonfiguration.
</Note>

<a id="WftyR" />

## Bestellung und Registrierung unterscheiden

Eine Bestellbestätigung oder die Bitte um Reservierung bestätigt noch keine abgeschlossene Domainregistrierung. Lassen Sie den aktuellen Status für den exakten Domainnamen prüfen. Dazu helfen Ihre Kundennummer und die Bestellreferenz.

Eine zugesagte Prüfung oder ein erneuter Registrierungsversuch bedeutet ebenfalls noch nicht, dass der Name erfolgreich registriert wurde. Planen Sie einen verbindlichen Start erst nach bestätigtem Abschluss.

<a id="aZU7a" />

## Angeforderte Unterlagen einreichen

Je nach Domainendung und eingetragenem Inhaber können zusätzliche Nachweise erforderlich sein. Maßgeblich ist die konkrete aktuelle Aufforderung des Registrars oder der Vergabestelle. Klären Sie, welches Dokument in welcher Form benötigt wird, welche Frist gilt und welchen sicheren Einreichungsweg Sie verwenden sollen.

Senden Sie keine Ausweiskopien vorsorglich oder an ungeprüfte Empfänger. Die Ankündigung, Unterlagen später zu schicken, ersetzt ihre Einreichung und Prüfung nicht. Fragen Sie nach, wenn Anforderungen oder Zuständigkeit unklar sind.

<a id="iOcB8" />

## Wann funktioniert E-Mail mit der Domain?

Nach der Registrierung müssen auch DNS und der gewünschte Maildienst bereitstehen. Prüfen Sie Postfächer oder Weiterleitungen sowie die zum Dienst passenden Einstellungen. Eine registrierte Domain allein richtet noch keinen Maildienst ein.

Testen Sie Versand und Empfang mit der vorgesehenen Adresse. Nutzen Sie für wichtige Nachrichten bis zur bestätigten Bereitstellung eine bereits funktionierende Adresse.

## Fragen zur Bestellung

<AccordionGroup>

<a id="ein-registrierungsversuch-ist-abgelaufen" />

<Accordion title="Ein Registrierungsversuch ist abgelaufen" id="oxLLN">

Bei einem Timeout muss der aktuelle Auftragsstatus geprüft werden. Ein abgelaufener Versuch kann bedeuten, dass weiterhin Unterlagen fehlen oder ein neuer Versuch nötig ist. Lassen Sie auch die aktuelle Verfügbarkeit des Namens bestätigen.

Geben Sie keine zweite Bestellung auf, bevor geklärt ist, was mit dem ersten Auftrag und einer möglichen Zahlung geschehen ist. Eine geschlossene Supportanfrage ist keine Bestätigung, dass die Domain registriert wurde.

</Accordion>

<a id="registrierung-oder-transfer" />

<Accordion title="Registrierung oder Transfer?" id="nqpmT">

Die Option „Transfer“ bedeutet, dass die Domain bereits registriert ist und zu einem anderen Anbieter umziehen soll. Sie bestätigt keine freie Verfügbarkeit. Für den Transfer müssen Sie Domaininhaber sein oder eine entsprechende Berechtigung haben.

Haben Sie eine fremde Domain versehentlich als Transfer bestellt, wenden Sie sich mit der Bestellreferenz an den Support, damit der Auftrag geprüft und korrigiert werden kann. Fordern Sie keinen AUTH-Code für eine Domain an, zu deren Verwaltung Sie nicht berechtigt sind. Lassen Sie sich die tatsächliche Auftragskorrektur bestätigen.

</Accordion>

<a id="eine-vergebene-domain-ohne-aktive-website-erwerben" />

<Accordion title="Eine vergebene Domain ohne aktive Website erwerben" id="Uyke_">

Eine leere oder nicht erreichbare Website bedeutet nicht, dass die Domain frei ist. Lassen Sie den aktuellen Registrierungsstatus des exakten Namens prüfen. Eine bestehende Registrierung kann nur mit entsprechender Zustimmung übernommen werden; ein Transferauftrag allein verschafft keine Berechtigung.

Wenn Sie den eingetragenen Inhaber kontaktieren möchten, nutzen Sie einen dafür vorgesehenen öffentlichen Kontaktweg oder fragen Sie den Support, ob eine Vermittlung möglich ist. Eine Weitergabe Ihrer eigenen Kontaktdaten muss mit Ihnen abgestimmt sein. Weder die Weiterleitung noch eine Antwort oder Verkaufsbereitschaft kann vorab zugesagt werden. Private Inhaberdaten werden nicht einfach an Kaufinteressenten herausgegeben.

Bei .at-Domains zeigt die Whois-Abfrage je nach Rechtsperson unterschiedliche Informationen. Aktuelle Hinweise zur Anzeige und zum Auskunftsverfahren finden Sie bei nic.at: [nic.at: Whois-Auskunft und Datenschutz](https://www.nic.at/de/meine-at-domain/domain-suche/whois-policy)

</Accordion>

<a id="inklusivdomain-und-hostingzuordnung-prüfen" />

<Accordion title="Inklusivdomain und Hostingzuordnung prüfen" id="4uCaN">

Wenn eine erwartete Inklusivdomain im Kundenbereich separat zur Verrechnung erscheint, prüfen Sie die vereinbarte Inklusivleistung und die Zuordnung zum konkreten Webhosting. Nennen Sie dem Support die betroffene Domain und den vorgesehenen Webhost.

War zuerst eine Fremddomain mit dem Hosting verknüpft, wird eine später registrierte oder transferierte Domain nicht unbedingt automatisch als Inklusivdomain zugeordnet. Lassen Sie die Zuordnung und die Abrechnung getrennt prüfen. Eine bestätigte Zuordnungsänderung ist noch keine Gutschrift und kein Funktionstest Ihrer Website oder E-Mail.

</Accordion>

</AccordionGroup>
