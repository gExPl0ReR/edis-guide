Mit einer Weiterleitung führen Sie Besucher einer Domain oder Webseite zu einer anderen Adresse.

## Weiterleitungsdienst im Kundenbereich

Ohne eigenen Webhost können Sie einen passenden Weiterleitungsdienst im Kundenbereich einrichten.

<a className="edis-button" href="https://manage.edis.at" target="_blank" rel="noopener noreferrer">Kundenbereich öffnen</a>

<Note>
  Je nach Domain-Tarif benötigen Sie dafür das Zusatzprodukt [„Aktive Nutzung“](/aktive-domain-nutzung).
</Note>

Verwenden Sie das **aktuell bestätigte DNS-Ziel des Dienstes**. Übernehmen Sie keine historische IP-Adresse pauschal für eine andere Domain oder Hostingzuordnung.

Prüfen Sie nach der Einrichtung:

- die Hauptdomain und die Adresse mit `www`;
- die Weiterleitung beim Aufruf über HTTPS;
- den Erhalt der benötigten DNS-Einträge für E-Mail.

## Weiterleitung mit .htaccess

<Steps>
  <Step title="Website-Verzeichnis prüfen">
    Bearbeiten Sie die `.htaccess` im tatsächlichen **Document-Root**, also im Stammverzeichnis der betroffenen Website.

    Beispiele sind `/www/home/` oder `/www/home/unterverzeichnis/`, wenn die Domain auf dieses Unterverzeichnis zeigt.
  </Step>

  <Step title="Bestehende Regeln sichern">
    Sichern Sie die vorhandene `.htaccess` und stimmen Sie die gewünschte Weiterleitung mit Ihrer Websitebetreuung ab.
  </Step>

  <Step title="Weiterleitung eintragen">
    Für eine **dauerhafte Weiterleitung** verwenden Sie HTTP **301**. Ersetzen Sie die Beispieladresse durch Ihr tatsächliches Weiterleitungsziel.

    ```apache .htaccess
    Redirect 301 / https://www.weiterleitungsziel.domain
    ```

    Für eine **vorübergehende Weiterleitung** verwenden Sie stattdessen **302**.
  </Step>

  <Step title="Ergebnis kontrollieren">
    Testen Sie die Startseite, Unterseiten und benötigte URL-Parameter. Das gezeigte Redirect-Beispiel kann den angehängten Pfad an die Zieladresse weitergeben.
  </Step>
</Steps>

<Note>
  HTTP 301 kennzeichnet eine dauerhafte Weiterleitung und ist ein Signal für Suchmaschinen, die Zieladresse zu bevorzugen. Die alte Adresse verschwindet dadurch nicht zwingend sofort aus dem Suchindex.
</Note>

Technische Details: [Redirect-Direktive von Apache](https://httpd.apache.org/docs/2.4/mod/mod_alias.html#redirect).

## Meta Refresh in HTML

Eine HTML-Seite kann den Browser nach einer Wartezeit zu einer anderen Adresse weiterleiten.

Erstellen Sie auf Ihrem Webhost eine Datei `index.html` mit folgendem Inhalt und ersetzen Sie die Beispieladresse durch Ihr Ziel:

```html
<html>
	<head>
		<meta http-equiv="refresh" content="5; URL=https://www.weiterleitungsziel.domain">
		<title>Meine Webseite</title>
	</head>
	<body>
	</body>
</html>
```

Die Zahl **5** steht für die Wartezeit in Sekunden. Die Weiterleitung wird vom Browser über die HTML-Seite ausgelöst.

Technische Details: [Meta Refresh bei MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/meta/http-equiv#refresh).
