EDIS hosting servers provide both ImageMagick and GraphicsMagick for server-side image processing. The paths to these binaries and the method for enabling the corresponding PHP extension depend on which hosting generation your account is on. Current "Kaffee" generation products (provisioned from June 2019 onward) use the paths described in the first section; older legacy products used a different versioned path structure, documented below for reference.

## Current Hosting Products (Kaffee Generation, June 2019 and Later)

### Binary Paths

On current EDIS hosting servers, the image processing tools are available at the following locations:

**ImageMagick**

```text
/usr/bin/im_6.9
/usr/bin/im_7.1
```

**GraphicsMagick**

```text
/usr/bin/
```

The `graphicsmagick` binary is located directly in `/usr/bin/` on current products.

### Enabling the imagick PHP Extension

To use ImageMagick from PHP, enable the `imagick` extension via a PHP.INI template in the vHost panel. Navigate to **Apache → PHP.INI Templates and PHP.INI Assignment** and add the following directive to the template assigned to your domain:

```ini
extension=imagick
```

<Note>
  PHP extensions must match the PHP version your domain is actually using. Always check the active PHP version for the affected domain in the vHost panel under **Apache → PHP Version** before making changes. Extension availability may differ between PHP versions.
</Note>

### PHP Extension Compatibility

When selecting or changing a PHP version, verify that your application is compatible with that version before applying the change. The imagick extension is listed as `-extension imagick` in some contexts — use the exact syntax shown in the PHP.INI template interface.

<Warning>
  gRPC and Protobuf are independent extensions unrelated to ImageMagick. Do not enable them as a general prerequisite for image processing — only activate them if your application explicitly requires them and you have confirmed their availability for your PHP environment.
</Warning>

### WordPress Users

WordPress includes built-in image editing capability. Before installing additional plugins such as "ImageMagick Engine", check whether WordPress can already use an available image editor on your hosting account. Coordinate any plugin installation and its settings with your site administrator, since plugin configurations interact with the server paths above.

## Legacy Hosting Products (Before June 2019)

The following paths are historical records for older EDIS hosting products. They are provided for reference only and are **not a current recommendation**. If you are on a legacy product, verify the actual available path on your specific server before configuring any application to use it.

| ImageMagick Version | Date         | Path              |
|---------------------|--------------|-------------------|
| 6.2.4               | 28 July 2009 | `/usr/bin/`       |
| 6.5.5-3             | 05 Oct 2009  | `/usr/bin/im_6.5/` |
| 6.6.0-4             | 05 Nov 2010  | `/usr/bin/im_6.6/` |
| 6.7.7               | 11 Mar 2013  | `/usr/bin/im_6.7/` |
| 6.9.2-8             | 12 Dec 2015  | `/usr/bin/im_6.9/` |
| 7.0.7-28            | 08 May 2018  | `/usr/bin/im_7.0/` |

<Warning>
  Support for legacy hosting configurations has been discontinued. If your account is on an older product generation, consider migrating to a current EDIS hosting product to benefit from maintained software versions and supported configurations.
</Warning>
