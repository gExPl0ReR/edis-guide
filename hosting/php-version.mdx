EDIS web hosting lets you set a different PHP version for each domain or subdomain independently. Because major PHP version changes can break themes, plugins, or custom code, you should verify compatibility and create a full backup before making any switch.

<Warning>
Always back up your website files and database before changing the PHP version. After the switch, thoroughly test your site — especially forms, plugins, and any custom PHP code — to confirm everything still works correctly.
</Warning>

## Change the PHP Version

<Steps>
  <Step title="Log in to the vHost panel">
    Go to [https://manage.edis.at/vhost/](https://manage.edis.at/vhost/) and sign in with your hosting credentials.
  </Step>
  <Step title="Open the PHP Version settings">
    In the left-hand navigation menu, click **Apache**, then select **PHP Version** from the submenu.
  </Step>
  <Step title="Edit the domain or subdomain">
    Find the domain or subdomain you want to update in the list. Click the **edit icon** (pencil symbol) next to it.
  </Step>
  <Step title="Select the new PHP version">
    Choose your desired PHP version from the dropdown list of available versions, then confirm your selection to save.
  </Step>
  <Step title="Verify your website">
    After saving, open your website in a browser and check that all pages, forms, and features work as expected. Pay particular attention to any plugins or extensions that may have strict PHP version requirements.
  </Step>
</Steps>

<Note>
You can assign a different PHP version to every domain and subdomain that resides in its own subdirectory. This means you can, for example, run a legacy application on PHP 7.4 on one subdomain while running a modern application on PHP 8.3 on another — all within the same hosting account.
</Note>

## PHP 7.3 End of Life on Older Hosting Products

If you are on an older EDIS hosting plan — such as the legacy **Smart**, **Starter**, or **Basic** products (end-of-life 2019) — the maximum available PHP version is **PHP 7.3**. Due to platform limitations on these older products, no PHP updates beyond 7.3 can be provided.

<Warning>
PHP 7.3 has reached its official end of life and no longer receives security updates from the PHP project. Running your website on an unsupported PHP version exposes it to known security vulnerabilities. EDIS strongly recommends migrating to a current hosting product to access PHP 8.x.
</Warning>

### Upgrade to a Current Hosting Plan

If you need a more recent PHP version, MySQL 8, or regular platform security updates, EDIS recommends upgrading to one of the current **Kaffee** hosting plans. The modern plans offer:

- PHP 8.x (with the ability to choose a specific 8.x release per domain)
- MySQL 8
- Regular platform and security updates
- A future-proof infrastructure
