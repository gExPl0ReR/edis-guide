SFTP (SSH File Transfer Protocol) transfers files over an encrypted SSH connection, making it significantly more secure than plain FTP. Unlike FTP, SFTP encrypts both your credentials and your file contents in transit, and it does not require separate ports for data transfers. Before you connect, make sure your hosting plan includes SSH/SFTP access — check your plan details in the [vHost management panel](https://manage.edis.at/vhost/).

## Prerequisites

- An active EDIS webhosting plan with SSH/SFTP access enabled.
- An SFTP-capable client such as [FileZilla](https://filezilla-project.org/), [Cyberduck](https://cyberduck.io/), [WinSCP](https://winscp.net/), or any terminal with `sftp` support.
- Your SSH connection credentials from the vHost panel.

## Step 1 — Find Your SFTP Connection Details

<Steps>
  <Step title="Log in to the vHost panel">
    Open [manage.edis.at/vhost/](https://manage.edis.at/vhost/) and sign in with your hosting credentials.
  </Step>
  <Step title="Navigate to SSH Access">
    In the menu, click **SSH Access** (SSH-Zugang). The panel displays your connection details: hostname, port, and username.
  </Step>
  <Step title="Note your credentials">
    Record the following values — you will need them in your SFTP client:

    | Field | Where to find it |
    |---|---|
    | Host / Server | Shown in **SSH Access** in the vHost panel |
    | Port | Shown in **SSH Access** (typically TCP 22) |
    | Username | Your SSH username for this webhost |
    | Password | The password you set for SSH access |
  </Step>
</Steps>

## Step 2 — Configure FileZilla for SFTP

FileZilla is a popular, free SFTP client available for Windows, macOS, and Linux. The steps below use FileZilla, but the same principle applies to any SFTP client.

<Steps>
  <Step title="Open the Site Manager">
    In FileZilla, go to **File → Site Manager** (or press `Ctrl+S` / `Cmd+S`).
  </Step>
  <Step title="Create a new site entry">
    Click **New Site** and give it a recognisable name, such as your domain.
  </Step>
  <Step title="Enter your connection settings">
    Fill in the fields as follows:

    - **Protocol:** SFTP – SSH File Transfer Protocol
    - **Host:** the hostname from your vHost panel
    - **Port:** the port from your vHost panel (typically `22`)
    - **Logon Type:** Normal
    - **User:** your SSH username
    - **Password:** your SSH password
  </Step>
  <Step title="Connect">
    Click **Connect**. FileZilla will attempt to establish an SSH connection to your server.
  </Step>
  <Step title="Verify the host key fingerprint">
    On your first connection, FileZilla displays the server's host key fingerprint and asks you to confirm it. Compare this fingerprint with the value provided by EDIS support before clicking **OK** or **Trust**. This step protects you against man-in-the-middle attacks.

    <Warning>
      Do not disable or bypass the host key check just to dismiss the warning. Accept the key only after confirming the fingerprint matches what EDIS support has provided.
    </Warning>
  </Step>
</Steps>

## Step 3 — Navigate to Your Web Root

Once connected, FileZilla places you in your home directory (`/home/vHostID/`). From there:

<Steps>
  <Step title="Open the www directory">
    Double-click the **www** folder. Inside you will find the **home** directory and potentially **cgi** and **log** directories, along with any application-specific files.
  </Step>
  <Step title="Navigate to the document root">
    Double-click **home** to enter the document root — this is the directory your domain resolves to by default, unless it is redirected to a subdirectory.
  </Step>
  <Step title="Upload your files">
    In the left-hand panel (your local machine), navigate to the files you want to upload. Drag them to the right-hand panel (your server), or right-click and choose **Upload**. FileZilla transfers the files over the encrypted SFTP connection.
  </Step>
</Steps>

<Tip>
  If your domain is mapped to a subdirectory rather than the document root, navigate into that subdirectory before uploading. Check your domain configuration in the vHost panel if you are unsure.
</Tip>

## Using SSH Key Authentication (Optional)

For improved security, you can authenticate with an SSH key pair instead of a password.

<Steps>
  <Step title="Generate an SSH key pair">
    On your local machine, generate a key pair using `ssh-keygen` (Linux/macOS/Windows terminal):

    ```bash
    ssh-keygen -t ed25519 -C "your-email@example.com"
    ```

    This creates a private key (keep this secret) and a public key (ends in `.pub`).
  </Step>
  <Step title="Add your public key to the server">
    Log in to your webhost via SFTP or SSH and add the contents of your `.pub` file to `~/.ssh/authorized_keys`. Contact [hosting@edis.at](mailto:hosting@edis.at) if you need assistance enabling key-based authentication for your plan.
  </Step>
  <Step title="Configure FileZilla to use your key">
    In the Site Manager, set **Logon Type** to **Key file** and browse to your private key file. FileZilla will use it automatically on the next connection.
  </Step>
</Steps>

## Recommended SFTP Clients

| Client | Platform | Notes |
|---|---|---|
| [FileZilla](https://filezilla-project.org/) | Windows, macOS, Linux | Free, widely used, supports SFTP and FTPS |
| [Cyberduck](https://cyberduck.io/) | Windows, macOS | Clean interface, supports SFTP and cloud storage |
| [WinSCP](https://winscp.net/) | Windows | Feature-rich, supports SFTP, SCP, and FTP |
| Terminal `sftp` | Linux, macOS, Windows | Built-in command-line client, no install needed |

<Info>
  SFTP uses a single encrypted channel for both commands and data — there are no separate data ports to open in your firewall. You only need outbound TCP port 22 to be permitted.
</Info>
