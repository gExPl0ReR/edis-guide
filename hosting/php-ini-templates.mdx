EDIS web hosting lets you define custom PHP configuration values through reusable php.ini templates in the vHost panel. A template lets you set directives such as `memory_limit`, `upload_max_filesize`, or `max_execution_time` for a specific domain or subdomain, without affecting the rest of your hosting account. You can create multiple templates and assign each one to a different domain or subdomain.

## What php.ini Templates Can and Cannot Do

Before creating a template, it is important to understand their scope:

- **Templates apply per domain.** A template must be explicitly assigned to a domain or subdomain to take effect — it does not apply globally across your account.
- **Product limits are hard limits.** Directives such as `memory_limit` and `max_execution_time` are constrained by your hosting plan's overall resource budget. A template cannot exceed these plan-level limits. If you need higher limits, you need to upgrade your plan.
- **`sendmail_from` is not a general mail fix.** According to the PHP manual, this directive only applies on Windows systems. For mail delivery on Linux hosting, configure your application to use a valid sender address and either the `mail()` function with a permitted From address or authenticated SMTP.

<Note>
After creating or updating a template, always verify the effective PHP configuration in your application (for example via `phpinfo()`) to confirm the values are actually being applied.
</Note>

## Create a php.ini Template

<Steps>
  <Step title="Log in to the vHost panel">
    Go to [https://manage.edis.at/vhost/](https://manage.edis.at/vhost/) and sign in with your hosting credentials.
  </Step>
  <Step title="Navigate to PHP.INI Templates">
    In the left-hand navigation menu, click **PHP**, then select **PHP.INI Templates**.
  </Step>
  <Step title="Create a new template">
    Click **Add Template** (or the **+** button) to open the template editor. Give the template a descriptive name so you can identify it easily when assigning it to domains later.
  </Step>
  <Step title="Configure your PHP directives">
    Enter the PHP configuration values you need. Common directives include:

    ```ini
    memory_limit = 256M
    upload_max_filesize = 64M
    post_max_size = 64M
    max_execution_time = 120
    max_input_time = 120
    ```

    Only include directives you actually need to override. Unnecessary changes can cause unexpected behaviour.
  </Step>
  <Step title="Save the template">
    Click **Save** to store the template. The template is now available to assign to any domain or subdomain in your account.
  </Step>
</Steps>

## Assign a Template to a Domain or Subdomain

Once a template is saved, you must assign it to the domain or subdomain where you want the settings to apply.

<Steps>
  <Step title="Open domain settings">
    In the vHost panel, navigate to **Apache** and select the domain or subdomain you want to configure.
  </Step>
  <Step title="Select the php.ini template">
    In the domain's configuration screen, locate the **PHP.INI Template** field and select your template from the dropdown.
  </Step>
  <Step title="Save and verify">
    Save the domain configuration. Open your website and verify that the PHP settings are active — for example by checking the output of `phpinfo()` in a temporary test file.
  </Step>
</Steps>

<Tip>
You can create several templates with different settings and assign them to different (sub)domains within the same hosting account. This is useful if you host multiple applications with different requirements, such as a CMS that needs a high `upload_max_filesize` alongside a lightweight contact-form site with minimal resources.
</Tip>

## Clarify Application Requirements Before Upgrading

System reports and status pages in applications like WordPress show the current PHP configuration of that installation — these values are not automatically the minimum requirements for your theme or plugin. Before concluding you need a plan upgrade:

1. Check the **official documentation** of the specific theme or plugin for its stated minimum PHP requirements.
2. Compare those requirements with the **effective PHP configuration** shown via `phpinfo()` in your environment (not just the vHost panel).
3. Confirm that your php.ini template is **assigned to the correct domain**.

If the required value genuinely exceeds your plan's hard limit, contact [hosting@edis.at](mailto:hosting@edis.at) to discuss a plan upgrade before making changes.
