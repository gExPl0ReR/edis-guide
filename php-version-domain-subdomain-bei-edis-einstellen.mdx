---
title: "PHP-Version für eine Domain oder Subdomain ändern"
---

Prüfen Sie vor einer PHP-Umstellung eine aktuelle Sicherung und die Kompatibilität von Anwendung, Themes und Erweiterungen. Wählen Sie eine für Ihr Projekt geeignete, unterstützte Version, die im konkreten Webhost angeboten wird. So ändern Sie die PHP-Version für eine Domain oder Subdomain bei EDIS:

1. **Anmelden**: Besuchen Sie den EDIS [Verwaltungsbereich](https://manage.edis.at/vhost)
2. **Apache-Konfiguration**:
   - Navigieren Sie im Menü zu **Apache**
   - Wählen Sie dann den Punkt **PHP Version&#x20;**&#x61;us.
3. **PHP-Version ändern**:
   - Klicken Sie auf das Bearbeitungszeichen (meist ein Stift-Symbol) neben der Domain oder SubDomain, für die Sie die PHP-Version ändern möchten.
   - Wählen Sie die gewünschte PHP-Version aus der Liste der verfügbaren Versionen aus und bestätigen Sie Ihre Auswahl.

Die ausgewählte PHP-Version gilt anschließend für die bearbeitete Domain oder Subdomain. Prüfen Sie danach, ob Ihre Website weiterhin korrekt funktioniert. Beachten Sie, dass Sie für jede Domain oder SubDomain, die in einem eigenen Unterverzeichnis liegt, eine individuelle PHP-Version festlegen können.
