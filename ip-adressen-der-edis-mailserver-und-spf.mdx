Beim Versand über EDIS können je nach Versandweg unterschiedliche Server und IP-Adressen beteiligt sein.

## Aktuelle Versandadressen finden

EDIS pflegt die für die externe E-Mail-Kommunikation verwendeten IP-Adressen im DNS-Namen **`spf.edis.at`**. Sie können die Auflösung beispielsweise mit [MXToolbox prüfen](https://mxtoolbox.com/SuperTool.aspx?action=a%3aspf.edis.at&run=toolpage).

## Die eigene Domain für SPF konfigurieren

Ein **SPF-Eintrag** legt fest, welche Server für Ihre Domain versenden dürfen. EDIS richtet bei neu angelegten Domains seit einigen Jahren passende SPF-Einträge für die eigene Mailinfrastruktur ein.

Prüfen Sie bei einer älteren Domain, ob ein SPF-Eintrag vorhanden ist und ob er alle tatsächlich verwendeten Versanddienste berücksichtigt. Die Anleitung zeigt, wie Sie die gepflegte EDIS-Referenz einbinden.
