## Werkzeuge für „Kaffee“-Hostingprodukte

Prüfen Sie, welche Variante Ihre Anwendung benötigt: ein **Kommandozeilenwerkzeug** oder eine **PHP-Erweiterung**.

| Werkzeug | Bisher dokumentierte Auswahl |
| --- | --- |
| ImageMagick | PHP-Modul `imagick` oder Werkzeugpfad `/usr/bin/im_6.9` beziehungsweise `/usr/bin/im_7.1` |
| GraphicsMagick | Passendes PHP-Modul oder Werkzeuge unter `/usr/bin/` |

Verwenden Sie den tatsächlich auf Ihrem Webhost verfügbaren Pfad.

### WordPress und PHP-Erweiterungen

Prüfen Sie zuerst, ob WordPress bereits einen geeigneten Bildeditor verwenden kann. Ein zusätzliches Plugin wie **ImageMagick Engine** ist nicht pauschal erforderlich; stimmen Sie die Installation mit Ihrer Websitebetreuung ab.

PHP-Erweiterungen müssen zur ausgewählten PHP-Version und zum Webhost passen. Historische Angaben zu PHP 8.0 oder 8.1 sind keine aktuelle Empfehlung. Prüfen Sie Anwendungskompatibilität und eine noch unterstützte PHP-Version.

Verwenden Sie bei Bedarf **vHost → Apache → PHP.INI Templates** und **PHP.INI Zuweisung**. Die bisherige Anleitung nennt dafür **`-extension imagick`**. Prüfen Sie die angebotene Einstellung in Ihrem konkreten Template.

**gRPC und Protobuf** sind keine allgemeinen Voraussetzungen für Bildverarbeitung. Aktivieren Sie zusätzliche Erweiterungen nur bei einer konkreten Anwendungsanforderung und bestätigter Verfügbarkeit.
