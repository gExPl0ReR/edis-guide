Mit dem Zusatzprodukt **„Aktive Nutzung“** verwalten Sie die DNS-Einstellungen Ihrer Domain und richten Weiterleitungen ein. Es eignet sich, wenn Sie Ihre Website bei einem anderen Anbieter oder auf einem eigenen Server bzw. VPS betreiben möchten. Auch externe E-Mail-Dienste wie Microsoft 365 lassen sich damit mit Ihrer Domain verbinden.

## Ihre Möglichkeiten im Überblick

<Card title="DNS selbst verwalten" icon="globe" horizontal>
  Sie erhalten Vollzugriff auf die DNS-Zone Ihrer Domain auf unseren Anycast-Nameservern. Damit passen Sie die DNS-Einträge an die Vorgaben Ihres Website- oder E-Mail-Anbieters an.
</Card>

<Card title="Domain weiterleiten" icon="arrow-right" horizontal>
  Leiten Sie Besucher Ihrer Domain auf eine bestehende Website weiter. Die gewünschte Zieladresse (URL) hinterlegen Sie im Kundenbereich.
</Card>

<Card title="E-Mails weiterleiten" icon="envelope" horizontal>
  Richten Sie im Kundenbereich eine Catch-all-Weiterleitung ein, um eingehende E-Mails an Ihre Domain an ein externes Postfach Ihrer Wahl weiterzuleiten.
</Card>
